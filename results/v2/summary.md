## 条件の違い(Jev と LLM)

- 候補の説明文・直前の会話・発話・指示文は同じものを渡した
- Jev は `state`(会話)と choice の質問として、LLM は system に指示と候補一覧、user に会話の JSON として受け取る
- LLM は Chat Completions、構造化出力(候補 id の enum)、`reasoning_effort: none`(参考の1構成だけ low)。gpt-6-sol の後継の gpt-6.1-sol は `none` に対応していないため使っていない
- LLM の system(指示と候補一覧)は全件で同じなので、OpenAI 側の自動プロンプトキャッシュが効いた。入力のうちキャッシュから読まれた割合の平均: gpt-6-luna(推論なし) 12候補 98%、gpt-6-luna(推論なし) 6分類 97%、gpt-6-sol(推論なし) 12候補 98%、gpt-6-sol(推論なし) 6分類 97%、gpt-6-luna(推論 low・参考) 12候補 98%。費用の表は実績(キャッシュ込み)とキャッシュなし換算の両方を載せた。Jev にはキャッシュの割引がない
